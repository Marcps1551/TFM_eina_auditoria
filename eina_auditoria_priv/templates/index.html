Com detecta l'eina si es compleix o no?

L'eina no valida la nomenclatura que feu servir. Comprova només:

  • Si hi ha dada o no: per a base legal, finalitat, termini de conservació, mesures de seguretat, etc., es considera que compleix si el camp té algun valor (el que sigui). Podeu escriure "consentiment", "art. 6.1.a", "contracte" o la vostra pròpia denominació.
  • Per a sí/no (CSV o formulari): per a DPO, transferències, política accessible, etc., l'eina es basa en el que indiqueu (sí/no, 1/0, true/false, etc.). Accepta diverses formes (sí, si, yes, 1, true, cert; no, n, 0, false).

És a dir: la informació sempre s'entra amb les nomenclatures que vosaltres poseu; l'eina només comprova que hàgiu omplert els camps i que les respostes sí/no siguin coherents. No interpreta el significat legal dels termes.

Començar una auditoria

Importeu les dades des d'un fitxer o introduïu-les manualment. Després executeu l'auditoria per obtenir el informe amb riscos i recomanacions.

Importar JSON Importar CSV Introduir dades manualment

Format JSON

Un únic fitxer JSON amb nom_organitzacio, data_auditoria, tractaments, politica_privacitat i configuracio_acces. Podeu usar dades_exemple/auditoria_exemple.json com a plantilla.

Format CSV

Un fitxer CSV amb una fila per tractament. A la segona pantalla podreu assignar cada columna del CSV al camp corresponent (nom, finalitat, base legal, termini de conservació, etc.).
